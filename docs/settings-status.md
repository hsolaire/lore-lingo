## 本轮修复

- 字幕底部常驻横杠改为悬停边角提示，保留左右拖动区域；空状态排版和工具栏层级更紧凑。
- 设置导航与表单层级简化，未接入翻译功能默认收起；更多功能通过可聚焦按钮操作。
- 读取失败不显示可覆盖配置的空表单；提交期间阻止重复保存，失败保留旧配置。
- 保存复用实际请求校验，支持无密钥 IPv6 回环服务；拒绝 URL 凭据、查询参数、片段和已有网络策略禁止的地址。
- 修正快捷键、字幕库与 OCR 面板文案，明确哪些配置尚未生效。
