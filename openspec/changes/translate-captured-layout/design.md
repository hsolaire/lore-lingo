## Context

当前 Vue 通过定时器模拟区域选择，Rust 仅提供全局坐标的单次区域截图，OCR 和翻译设置页也没有连接生产服务。现有 `support-windows-macos` 变更正在建立长期的跨平台捕获会话边界，但明确不包含 OCR 和翻译。本变更在不改变该边界的前提下交付一个 macOS 可用的单次截图翻译流程，并让 OCR、翻译和结果 DTO 可以在后续接入正式捕获会话。

截图内容和译文可能包含敏感信息。不持久化截图和 OCR 文本；API key 仅持久化到系统钥匙串或凭据管理器；原始图像只在一次任务及当前结果与预览生命周期内存在。

## Goals / Non-Goals

**Goals:**

- 用户通过明确操作框选一个显示器内的区域，并在任务完成后看到保留空间布局的译文。
- OCR 输出稳定文本块 ID、阅读顺序、归一化边界框、原文和置信度。
- 翻译按稳定 ID 返回并验证完整性，避免译文错配到其他区域。
- 提供原文、译文和双语三种结果模式，以及加载、空、错误、取消和重试状态。
- 将平台 OCR、远程翻译、领域整理和 Vue 渲染放在清晰边界中。

**Non-Goals:**

- 连续视频 OCR、字幕匹配或实时翻译。
- 跨显示器选区、窗口自动吸附、复杂标注工具或贴图窗口。
- 擦除原文后的背景修复、像素级复刻字体或旋转文本排版。
- 第一版 Windows OCR 和表格语义单元格检测；Windows 返回显式不支持状态。
- OCR 预设、快捷键、窗口状态等尚未接入配置的编辑保存。

## Decisions

### 1. 单次任务使用状态化服务，但结果使用稳定 DTO

Rust 的 `CaptureTranslationService` 持有至多一个活动任务、预捕获的显示器图像和单次任务的翻译配置快照。Tauri 命令只负责校验请求、调用服务并返回稳定 DTO。开始新任务时先取消并清理旧任务，所有成功、失败和取消路径都销毁临时选择器窗口。

备选方案是把截图 base64、OCR 和翻译全部放在 Vue。该方案会让大图重复经过 IPC，并把原生权限、网络凭据和任务所有权泄漏给 WebView，因此不采用。

### 2. 选择器显示冻结截图并返回显示器局部逻辑坐标

开始任务时 Rust 在创建选择器窗口之前通过 macOS 14+ 的 ScreenCaptureKit 单帧 API 缓存每块显示器的 PNG，然后为每块显示器创建临时、无边框、置顶窗口。选择器页面把缓存图作为背景，仅绘制暗色遮罩、选框和尺寸。拖拽必须限制在开始显示器内，并返回 `monitor_id` 与局部逻辑矩形；Rust 按显示器缩放换算并裁剪缓存图。

这与长期 `screen-capture-session` 的坐标契约一致，后续可替换为正式捕获服务而不改变 OCR 和结果模型。

### 3. `LayoutDocument` 使用归一化几何和稳定块 ID

文档包含捕获图像尺寸、PNG、源/目标语言以及按阅读顺序排列的 `LayoutBlock`。块边界采用左上角原点的 0 到 1 归一化矩形，避免结果视图缩放时重复做物理像素换算。第一版块类型为标题、段落和列表项；无法可靠分类时使用段落。

Vision 的坐标原点在左下角，macOS adapter 负责转换。领域层负责排序、稳定 ID 和基础块分类，Vue 不接触 Vision 类型。

### 4. macOS Vision 是第一版真实 OCR 后端

macOS adapter 通过目标限定的 Objective-C 绑定调用 `VNRecognizeTextRequest`，使用 accurate 模式并返回最佳候选。图像解码或 Vision 请求失败映射为结构化错误。非 macOS backend 返回 `unsupported_capability`，不生成示例文本。

备选方案是第一版打包 PaddleOCR。它对复杂文档更强，但会显著增加运行时、模型体积和签名发布复杂度，因此延后到需要表格语义时评估。

### 5. 翻译使用 ID 保序的 OpenAI 兼容 JSON 协议

翻译服务一次提交有界文本块数组，要求返回 `translations: [{ id, text }]`。Rust 验证 ID 不重复、不缺失、不新增且响应大小受限，然后把译文映射回原块。endpoint 支持 HTTP 和 HTTPS；HTTP 适用于用户明确配置的兼容服务，API key 从系统凭据存储恢复后只在请求和配置内存中使用，不写入日志、localStorage 或数据库。

缺少 endpoint、模型或远程 endpoint 的 API key 时返回 `translation_not_configured`。网络、超时、HTTP 和协议错误使用稳定代码，不把 Authorization 或原始响应暴露给 Vue。

### 6. 结果使用可缩放图片画布加 DOM 文本层

主窗口在结果存在时切换为工作区布局：截图保持宽高比，文本块使用绝对定位 DOM 覆盖。原文模式不覆盖截图；译文模式使用高对比度半透明表面覆盖原块；双语模式同时显示紧凑原文和译文。字体大小受块尺寸约束并允许换行，过长内容滚动而不扩大几何块。

备选方案是把结果重新绘制为位图。DOM 更易实现自适应文本、复制、键盘访问和多模式切换；导出合成图片不在第一版范围。

## Risks / Trade-offs

- [Vision 文本观察结果不等同于完整文档结构] -> 第一版承诺保留空间布局和基础阅读顺序，不声称支持复杂表格语义；保留后端接口供后续布局模型替换。
- [远程翻译会发送截图中的识别文本] -> 仅在用户显式发起后调用，界面标识远程服务配置，且不持久化捕获内容。
- [大截图通过结果 IPC 增加内存] -> 限制捕获像素和编码大小，只保留当前结果，开始新任务时释放旧结果。
- [多显示器和 Retina 坐标容易错位] -> 选择器只报告显示器局部逻辑矩形，Rust 使用显示器 scale factor 换算并用单元测试覆盖裁剪边界。
- [选择器或网络失败可能让主窗口保持隐藏] -> 所有终态统一关闭选择器并恢复主窗口；前端提供可重试错误状态。
- [OpenAI 兼容端点响应并不完全一致] -> 使用最小聊天补全协议和严格 JSON 校验；协议不兼容时返回明确错误。

## Migration Plan

1. 先加入领域 DTO、纯布局整理及验证测试，不改变现有界面。
2. 加入 macOS Vision、翻译客户端和任务服务，保留现有 legacy 截图命令。
3. 加入选择器入口和结果工作区，再把“自定义区域”操作切到新任务。
4. 原生验证完成后移除旧的定时器模拟；窗口列表接入同一个单次 OCR/翻译流程，来源解析继续复用跨平台 DesktopService；长期连续会话仍由跨平台捕获变更接管。
5. 回滚时可恢复前端旧入口并移除新增命令；本变更没有持久化数据迁移。

## Open Questions

- Windows OCR adapter 将使用 Windows.Media.Ocr 还是共享的本地 OCR 引擎，由后续 Windows 原生验证决定。
- 复杂表格、漫画气泡和竖排文字是否需要独立布局模型，将根据真实样本准确率决定。
- API key 通过原生存储适配器保存在 macOS 钥匙串或 Windows 凭据管理器；Windows 实机验证待完成。

### 7. 四入口工具栏与设置页共用配置

顶部保留翻译选项、捕获窗口、捕获区域和设置。服务地址、模型与 API key 从设置页读写 Rust 的持久化配置服务；开始区域或窗口任务时读取同一配置并合并工具栏语言方向。地址、模型和默认语言保存在 SQLite，密钥仅在原生系统存储中保留。读取时恢复同一默认模型，工具栏临时语言切换仍只在当前会话中生效。

截图完成后先广播携带真实 PNG 的 processing 状态，再执行 OCR 与翻译。空结果和翻译错误保留该图；区域按钮以截图存在判断已捕获，悬停或聚焦显示缩略图。关闭版面结果只关闭视图，开始新任务或取消任务才释放当前结果。窗口捕获复用目录版本与不透明来源 ID，不将原生窗口编号发送到 Vue。

### 8. 区域坐标修订与实时画面

区域捕获成功后独立保留显示器局部逻辑边界，点击已捕获入口编辑四个坐标。面板内的预览只刷新本地缩略图；翻译必须显式点击，先停预览并等待捕获退出，再对修订后的坐标截图。前端清理计时器、丢弃过期响应，后端校验坐标与修订并限制单帧并发；预览不写入磁盘、不启动 OCR 或远程模型请求。

### 9. 设置校验与功能状态说明

设置页将可用的服务配置与未完成能力分开展示。服务表单保留加载、读取失败、草稿修改、应用中与应用结果状态，读取失败时仅提供重试，避免空表单覆盖当前配置；撤销草稿不调用后端。字段错误提供与输入关联的无障碍提示。保存成功表示配置通过校验且持久化完成，不代表模型存在或服务连通。

Rust 保存配置与实际翻译复用同一端点校验：拒绝地址内的凭据、查询参数、片段和已有策略禁止的网络地址；远程服务要求密钥，IPv4/IPv6 回环服务允许留空。校验失败不改变旧配置。自动翻译、历史和字幕优先匹配仍未完成；连续 OCR 的采样和去重预设仅为配置记录，不描述为单次捕获已生效。

### 10. SQLite 与系统凭据的保存边界

复用 `sys_model_profiles` 的地址、模型、`secret_ref` 与 `sys_translation_settings` 的默认模型指针、语言方向；仓储以参数化事务更新两张表，保留未编辑的偏好和选项，已有迁移不变。独立 `TranslationConfigService` 负责协调仓储与平台凭据适配器，Tauri 读写命令使用阻塞工作线程；读取和保存只持有设置专用锁，不阻塞捕获或网络请求。

保存先完成与请求一致的输入校验，再用随机引用暂存发生变化的密钥并验证可读，数据库提交后才切换权威配置并尽力删除不再引用的旧条目。数据库失败回滚所有配置记录并清理暂存凭据，保留旧密钥。清理失败或跨存储提交窗口中崩溃可能留下孤立系统条目；不以此撤销成功提交或写入明文降级存储。

凭据条目缺失时，仍恢复非密钥字段，供用户重新填写；访问被拒绝与数据库错误使用安全的结构化错误，设置页禁用覆盖保存并提供重试。密钥不进入 SQLite、文件、浏览器存储、诊断与测试夹具；测试密钥在内存随机生成。真实系统烟雾测试使用隔离数据库与临时条目，并启动独立进程重新读取，结束后清理。
